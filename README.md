# 🚗 Gestor de Vehículos

¡Hola! 👋 Este proyecto es una aplicación web sencilla para administrar un inventario de vehículos consumiendo una API REST con **JavaScript Vanilla**.

---

## 🌐 Visitar la web

📌 **Pruébalo en vivo aquí:**  
👉 [Ver live demo](https://sebaxlandaeta.github.io/vehiculos-api-rest/)

---

## ✨ ¿Qué hace esta app?

* 📥 **Consulta vehículos:** Carga los datos guardados en la API al iniciar (`GET`).
* ➕ **Agrega vehículos:** Añade nuevos registros desde un formulario validado (`POST`).
* 🗑️ **Elimina vehículos:** Borra elementos de la lista y del servidor (`DELETE`).
* 🔔 **Alertas y Carga:** Usa **SweetAlert2** para notificaciones y muestra un loader mientras procesa.

---

## 🛠️ Tecnologías

* 📄 **HTML5**
* ⚡ **JavaScript Vanilla** (Fetch API)
* 🎨 **Tailwind CSS (vía CDN):** Usado directamente desde su enlace CDN en el HTML, permitiendo estilizar la interfaz rápido y sin necesidad de instalar o compilar paquetes.
* 🚨 **SweetAlert2 (vía CDN)**
